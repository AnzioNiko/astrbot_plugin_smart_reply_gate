# 更智能的回复

通过关键词、正则表达式或群聊概率抽样触发 AstrBot 回复，并可在主模型处理消息前用判断器评估是否值得回复。判断器总开关默认开启；关闭后仍按插件触发规则路由消息，但跳过判断器并直接放行主模型。

## 与 AstrBot 官方唤醒词的区别

本插件的关键词和正则在消息正文任意位置匹配，命中后进入普通 LLM 回复流程；是否经过回复判断由判断器总开关控制。它们不是 AstrBot 官方唤醒词，也不会作为工具指令使用。两类触发可以同时启用，任一命中即触发。对应列表留空即可关闭那一类规则。

普通群聊中仅 @BOT 时仍按 AstrBot 原行为处理，不经过本插件判断器；如果该发送者处于跟进窗口内，则按跟进窗口的判断开关处理。若同一条消息同时 @BOT 并命中本插件关键词或正则，则作为插件明确触发处理。

## 功能

- 在关键词列表中逐项添加关键词，消息包含任意一项即命中；列表留空时关闭关键词规则。
- 在正则列表中逐项添加规则，任一正则在消息任意位置匹配即命中；列表留空时关闭正则规则，无效正则记入日志并忽略。
- 从旧版升级时，插件会在加载时把原有的换行文本关键词和正则配置迁移成列表并保存。
- 私聊规则默认关闭。开启后，仅命中关键词或正则的私聊消息进入判断；未命中时阻止 AstrBot 默认回复。
- 判断器可选 AstrBot Provider 或 TypeSafe。AstrBot Provider 从已有 Provider 下拉选择；留空时沿用当前对话模型。TypeSafe 使用官方 SDK、API Key 和可选模型 ID（默认 `jev-latest`）。
- 是否回复判断有独立总开关，默认开启。关闭后关键词、正则、主动抽样和跟进窗口消息都绕过判断器；判断器模式、模型、阈值、判断说明和超时设置会隐藏。
- 判断器支持 Noul 二元判断和 Score 五级评分；TypeSafe Noul 默认阈值为 0.5，Score 默认最低 3 分。普通 AstrBot Provider 的 Noul 按模型返回的布尔值判断，不使用数值阈值。
- 判断请求提供当前消息、最近 5 条对话和当前会话使用的人格提示词。人格提示词帮助判断器识别机器人名称、自称和别名；如果用户是在称呼机器人并自然问候、提问、请求帮助或接话，会倾向于允许回复。
- 群聊主动回复独立开关，默认关闭。白名单为空时所有群可参与；非空时只对名单内群抽样。群消息每条独立抽样，默认概率 10%，不排除其他机器人账号。
- 主动回复支持固定冷却和能量限频。默认固定冷却 300 秒；能量模式按群隔离，默认上限 100、成功消耗 30、每 30 秒恢复 1 点、门槛默认 50 点后参与抽样。门槛留空时自动跟随成功回复的能量消耗值。能量持久化，重启后按停机时间恢复。
- 同一发送者消息跟进有独立总开关，默认开启。插件回复或普通 @BOT 回复发送成功后，会为该群原发送者开启默认 30 秒跟进窗口。窗口消息默认先经过“是否值得回复”判断；可单独关闭跟进判断，或通过判断总开关统一关闭判断。窗口不跨重启。关闭跟进总开关会清除已有窗口并停止创建和触发跟进。续聊刷新默认关闭；开启后收到续聊消息时立即刷新计时。
- 每次判断、拒绝、抽样未命中、限频跳过和错误回退都会记入 AstrBot 日志。

## 判断失败时的处理

- 关键词/正则明确触发：判断器报错或超时会记录错误并放行主模型。
- 主动回复抽样：判断器报错或超时会记录错误并跳过本次回复。
- 判断器总开关关闭时，所有插件触发分支直接放行主模型。
- 跟进窗口是否调用判断器由跟进开关及判断总开关共同控制；开启判断时遇到故障会记录错误并放行主模型。未处于跟进窗口的普通 @BOT 和其他插件/工具触发的请求仍不会被本插件判断。

## 主动回复与 AstrBot 设置

插件的群聊主动回复有独立概率和限频配置，不会修改 AstrBot 自带的随机概率主动回复设置。如果两者同时开启，可能对同一消息重复回复；请按需要关闭其中一套。

## 配置界面说明

判断器总开关关闭时，判断器模式、模型、阈值、判断说明及超时设置会隐藏。开启后，AstrBot Provider 和 TypeSafe 设置按“判断器模式”显示；Noul/Score 阈值按对应选项显示。关闭“启用同一发送者消息跟进”后，跟进判断、时长和续聊刷新设置会隐藏。

## 安装 TypeSafe 依赖

插件的 `requirements.txt` 固定使用 [TypeSafe 官方文档](https://core.elsaifoundry.ai/guides/typesafe.html)提供的 Python SDK 和包索引。选择 TypeSafe 前请确认 AstrBot 已成功安装该依赖；普通 AstrBot Provider 模式不需要填写 TypeSafe Key。

## 实现边界

插件在消息事件处理中对自己的触发分支先运行判断器，再通过 AstrBot 默认回复链路处理获准消息，以保留 AstrBot 当前会话和角色上下文。AstrBot 若为该会话配置了 Agent 工具，获准后的默认处理仍可能按 AstrBot 原配置调用工具。
